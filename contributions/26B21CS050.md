## Three Git Commands I Learned

1. `git init` — Initializes a local Git repository.
2. `git commit -m "message"` — Saves staged changes as a commit.
3. `git push` — Uploads local commits to a remote repository.

## Purpose of GitHub

GitHub is a platform for hosting Git repositories, managing source code, collaborating with other developers, and tracking project changes.

## One Benefit of Using Branches

Branches allow developers to work on new features or documentation separately without directly affecting the main branch. Changes can be reviewed before merging.
